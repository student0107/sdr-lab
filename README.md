# SDR_LAB

Одностраничный лендинг про Software Defined Radio (SDR), RTL-SDR и HackRF One.

## Запуск

Откройте `index.html` в браузере (двойной щелчок или «Открыть файл»).

Фоновое фото загружается с Unsplash — нужен интернет. Чтобы работать офлайн, положите `bg.jpg` в эту папку и в CSS замените URL в `.page-bg` на `url("bg.jpg")`.

## Стек

Чистые HTML, CSS и JavaScript в одном файле — без сборки и фреймворков.
